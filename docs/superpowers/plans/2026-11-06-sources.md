# SRC-01a official read-only evidence plan

Goal: let a signed-in user retrieve genuine official eligibility documentation and inspect auditable evidence while live registration remains disabled.
Spec: docs/product/SOURCES.md. Existing user delegation permits autonomous design/stack decisions and multi-agent execution. Keep current isolated branch work, preserve prior increments; no worktree required.

Architecture: a fixed registry in hunter/sources.py owns the sole HTTPS source URL; API accepts a registry ID, never a URL. Separate transport from authenticated app requests, use inherited proxy and TLS trust, refuse redirects, impose 10-second request timeouts and 256 KiB decoded-body bound. No credentials/user data sent to source. Add owner-scoped state to SQLite and include it in account export/deletion. Do not hold database transaction during network I/O. Synthetic executor catalog remains independent.

Tasks:
1. PM/BA document source scope, unknown facts, fixed-source boundary and acceptance. Correct stale AUTH-01a backlog status without claiming whole auth readiness.
2. Backend writes tests first for bounded transport and state behavior, adds source module and API integration. POST refresh claims persistent 60-second cooldown before I/O, stores hash/excerpt/retrieval time, retains previous evidence on failure. GET computes 24-hour freshness.
3. Frontend adds separate Sources tab with explicit read-only action, evidence, changed/stale/error states, safely rendered text. No external submit control.
4. Independent QA covers authentication/CSRF, owner isolation, bounded/redirect/error transport, persistent cooldown, privacy integration and browser behavior; new tests live in test_source_api.py, backend tests in test_sources.py.
5. Independent code reviewer examines exact destination constraints, transport safety, lock/claim behavior, truthfulness and privacy. Fix high defects, rerun affected checks.
6. Lead runs full regression, previous and new real-browser smoke, real fixed-source HTTP request, syntax/compile checks, commit/push and progress evidence. Report remote CI unverified unless directly observed.

Review focus: unexpected redirects, large streamed text, upstream failures with retained stale evidence, cross-account deletion/export, malicious text posing as tool instructions. No model output or retrieved content may authorize execution. No generic URL fetch/SSRF resistance claim from this fixed registry slice.
